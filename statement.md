# Project Statement

## Project Title

Smart Campus Management System

## Problem Statement

Managing different campus activities such as student records, attendance, events, and complaints can become difficult when these activities are handled separately.

Students and administrators need a simple and organized system to manage and access campus-related information efficiently.

The Smart Campus Management System is developed as a Java-based console application that provides a centralized platform for managing essential campus activities. The system helps organize student information, attendance records, campus events, and student complaints while providing an administrative dashboard for monitoring the system.

## Scope

The scope of this project includes the management of the following campus activities:

- Student information management
- Student attendance management
- Campus event management
- Student event registration
- Complaint submission and status management
- Administrative dashboard and system statistics
- Input validation and error handling

The current version is a console-based application and stores data during program execution. It can be extended in the future with database connectivity, user authentication, and a graphical or web-based interface.

## Target Users

The primary users of the system are:

### Students

Students can be associated with campus activities such as attendance, events, and complaints.

### Administrators

Administrators can manage student records, create and manage events, monitor complaints, and view overall system statistics.

## High-Level Features

### 1. Student Management

- Add new students
- View all students
- Search students using Student ID
- Delete student records
- Prevent duplicate Student IDs

### 2. Attendance Management

- Record student attendance
- Calculate attendance percentage
- View attendance records
- Validate attendance values
- Display a warning when attendance is below 75%

### 3. Event Management

- Create campus events
- View available events
- Register students for events
- Prevent duplicate event registration
- Prevent registration when an event is full

### 4. Complaint Management

- Submit complaints
- View submitted complaints
- Update complaint status
- Manage complaint statuses:
  - PENDING
  - IN_PROGRESS
  - RESOLVED

### 5. Admin Dashboard

- Display total number of students
- Display total attendance records
- Display total events
- Display total complaints
- Display complaint status statistics

### 6. Input Validation and Error Handling

- Handle invalid numeric input
- Prevent duplicate student and event IDs
- Validate attendance values
- Validate event capacity
- Check whether students and events exist before related operations
- Handle invalid complaint operations

## Project Objective

The main objective of this project is to develop a simple, modular, and organized campus management system using Java and Object-Oriented Programming concepts.

The project aims to provide a centralized system for managing important campus activities while demonstrating practical implementation of:

- Classes and Objects
- Encapsulation
- Abstraction
- Inheritance
- Method Overriding
- Collections using ArrayList
- Exception Handling
- Modular Programming
- Input Validation

## Expected Outcome

The expected outcome of this project is a functional Java-based campus management application that allows users to efficiently manage student records, attendance, events, and complaints through a structured console interface.

The system also provides an administrative dashboard to give an overview of the campus data managed by the application.
